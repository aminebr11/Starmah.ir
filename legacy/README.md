# کد قدیمی (Legacy) — ستاره ماه ۱.۰

این پوشه نسخه‌ی اصلی سایت را برای **مرجع و مهاجرت** نگه می‌دارد:

- `www.zip` — سورس PHP خام نسخه‌ی ۱
- `qwaepiuv_starmah_db.sql` — دامپ دیتابیس نسخه‌ی ۱

> ⚠️ امنیت: `config.php` داخل zip شامل کلیدهای API و رمز دیتابیس است. در نسخه‌ی ۲ همه‌ی اسرار به `.env` منتقل شده‌اند. توصیه: کلیدهای قدیمی revoke شوند.

منطق‌های ارزشمند برای پورت به نسخه‌ی ۲: محاسبه‌ی XP/سطح، آزمون‌ساز، یکپارچگی AI (Claude/OpenAI)، توابع تاریخ جلالی.
